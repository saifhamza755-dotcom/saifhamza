# قائمة تجهيز النشر والتسليم

- [ ] تغيير `APP_ENV` إلى `production` وتعطيل `APP_DEBUG`.
- [ ] إنشاء مفتاح تطبيق مستقل على الخادم.
- [ ] استخدام مستخدم قاعدة بيانات محدود الصلاحيات وكلمة مرور قوية.
- [ ] حذف الحسابات التجريبية وتغيير جميع كلمات المرور.
- [ ] تفعيل HTTPS وإجبار الاتصال الآمن.
- [ ] ضبط صلاحيات مجلدي `storage` و`bootstrap/cache` فقط.
- [ ] منع الوصول العام إلى `.env` و`storage/app/private`.
- [ ] إعداد نسخ احتياطي دوري لقاعدة البيانات والأدلة.
- [ ] إعداد مهام Laravel المجدولة وQueue عند إضافة البريد أو المهام الخلفية.
- [ ] تشغيل `php artisan optimize` بعد النشر.
- [ ] تشغيل الاختبارات على نسخة تجريبية قبل الإنتاج.
- [ ] تجربة رحلة كاملة لكل دور وتوثيق قبول المستخدم.
- [ ] إعداد مستودع Git خاص وعدم رفع `.env` أو الملفات السرية.
- [ ] وضع سياسة لحفظ الأدلة والخصوصية وصلاحيات الاطلاع.
