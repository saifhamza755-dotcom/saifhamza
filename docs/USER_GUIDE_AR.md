# دليل استخدام منصة الجودة والاعتماد

## تسلسل العمل

1. ينشئ مسؤول النظام المستخدمين والتكليفات.
2. تبني الإدارة المركزية الهيكل المؤسسي وإصدار المعايير.
3. تنشئ الإدارة المركزية دورة تقييم وتحدد الجامعات والكليات.
4. ينفذ مسؤول جودة الكلية التقويم الذاتي ويرفع الأدلة ثم يرسله.
5. يراجع العميد الدرجات والأدلة ويعتمد التقرير أو يعيده.
6. يجمع مسؤول الجامعة تقارير الكليات في تقرير جامعي ويرسله.
7. تعتمد الإدارة المركزية التقرير وتعيّن مقيمًا خارجيًا.
8. ينفذ المقيم التقييم الخارجي ويرسله للاعتماد.
9. تنشئ الكلية أو الجامعة خطة تحسين وتتابع الإجراءات.
10. تصدر الإدارة المركزية قرار الاعتماد والتقرير النهائي.

## ملاحظات مهمة

- لا يمكن تعديل إصدار معايير بعد اعتماده.
- لا يمكن إرسال تقويم ناقص الدرجات أو الأدلة المطلوبة.
- الملفات خاصة ولا تُحمّل إلا من مستخدم مخول داخل نطاق الكلية.
- لا يمكن اعتماد تقرير كلية قبل قبول الأدلة.
- لا يمكن إنشاء تقرير جامعي قبل اعتماد جميع الكليات المشاركة.
- تُسجل العمليات الحساسة في سجل التدقيق.
- يظهر جرس الإشعارات في رأس الصفحة، وينقل الإشعار إلى المعاملة المرتبطة.
