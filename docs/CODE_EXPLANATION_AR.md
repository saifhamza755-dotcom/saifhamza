# دليل شرح الكود باللغة العربية

هذا الملف مُعد للمناقشة الأكاديمية. لا يحتوي على منطق تشغيلي؛ بل يشرح أين توجد كل وظيفة مهمة في المشروع وما الذي تفعله.

## 1. فكرة المشروع

المشروع منصة Laravel لإدارة الجودة والاعتماد في مؤسسات التعليم العالي. تتشارك جميع الأجهزة قاعدة بيانات MySQL واحدة، ولذلك فإن إنشاء الطلبات والتقارير والتكليفات وتغيير الحالات لا يعتمد على تخزين الهاتف أو المتصفح.

تدفق العمل الرئيس هو:

1. مسؤول النظام ينشئ الحسابات والتكليفات.
2. الإدارة المركزية تدير الجامعات والمعايير ودورات التقييم.
3. مسؤول الكلية ينفذ التقويم الذاتي ويرفع الأدلة.
4. العميد يراجع تقرير الكلية.
5. مسؤول الجامعة يجمع التقارير ويعيد تقرير كلية عند الحاجة.
6. فريق التقييم الخارجي يقيّم الجامعة.
7. الإدارة المركزية تسجل قرار الاعتماد.

## 2. الملفات التي يبدأ منها التشغيل

| الملف | الشرح العربي |
|---|---|
| `routes/web.php` | جدول روابط النظام: يربط كل رابط بدالة Controller ويضع حماية تسجيل الدخول والصلاحيات. |
| `app/Http/Controllers/PlatformController.php` | يفتح واجهة المنصة ويضع روابط API وبيانات المستخدم النشط داخل JavaScript. |
| `public/platform/js/app.js` | الواجهة العربية التفاعلية: يرسم الصفحات، يفتح النوافذ، ويرسل طلبات API إلى Laravel. |
| `public/platform/js/core.js` | قواعد نموذج العرض المحلي فقط؛ بقي للعرض والنسخ الاحتياطي، أما العمليات الأساسية فتُرسل الآن إلى الخادم. |
| `database/seeders/DatabaseSeeder.php` | ينشئ بيانات البداية: الأدوار، الصلاحيات، جامعة صنعاء، الكليات، والحسابات التجريبية. |

## 4. النماذج Models والعلاقات

كل Model يمثل جدولًا في قاعدة البيانات، والعلاقات المكتوبة بدوال مثل `belongsTo` و`hasMany` هي روابط بين الجداول.

| النموذج | وظيفته |
|---|---|
| `User` | المستخدم، كلمة مروره، حالته، وتكليفاته. الدالتان `hasRole` و`hasPermission` تتحققان من الدور الفعّال في الجلسة. |
| `UserAssignment` | يربط المستخدم بدور ونطاق جامعة أو كلية؛ وهو أساس تعدد الأدوار. |
| `Role` و`Permission` | تعريف الأدوار والصلاحيات وربطها ببعضها. |
| `University` و`College` و`Department` و`AcademicProgram` | الهيكل المؤسسي المتدرج. |
| `StandardsVersion` و`Standard` و`Indicator` | إطار الجودة وإصداراته ومعاييره ومؤشراته وأوزانها. |
| `EvaluationCycle` | دورة التقييم وفترتها والجامعات والكليات المشاركة فيها. |
| `SelfAssessment` و`AssessmentResponse` و`EvidenceFile` | التقويم الذاتي ودرجات مؤشرات الكلية والأدلة المرفوعة. |
| `UniversityReport` | التقرير الموحّد للجامعة الناتج من تقارير الكليات المعتمدة. |
| `EvaluationTeam` و`EvaluationVisit` | فريق التقييم الخارجي وزياراته. |
| `ExternalEvaluation` و`ExternalEvaluationResponse` | تقرير التقييم الخارجي ودرجاته. |
| `ImprovementPlan` و`ImprovementAction` | خطة التحسين وإجراءاتها ونسبة إنجازها. |
| `AccreditationRequest` و`AccreditationDecision` | طلب الاعتماد وقرار الاعتماد. |
| `AppNotification` و`AuditLog` | إشعارات المستخدمين وسجل العمليات للتتبع والمراجعة. |

## 5. الحماية والصلاحيات

- `EnsurePermission`: يمنع تنفيذ الرابط إذا لم يملك المستخدم الصلاحية المطلوبة.
- `EnsureRole`: يمنع تنفيذ الرابط إذا لم يكن دور المستخدم من الأدوار المطلوبة.
- `User::hasPermission`: لا يفحص جميع تكليفات المستخدم عشوائيًا؛ بل يفحص التكليف الفعّال المحفوظ في الجلسة.
- كل Controller يعيد التحقق من النطاق (الجامعة والكلية) في الخادم، ولا يعتمد على ما ترسله الواجهة فقط.

## 6. شرح واجهة JavaScript

| الجزء | المهمة |
|---|---|
| `sessionUser` | يحدّث نسخة الواجهة من بيانات المستخدم التي رجعها Laravel. |
| `api` | دالة موحدة لإرسال طلبات JSON مع CSRF Token وإظهار أخطاء الخادم. |
| `refreshDirectory` و`refreshQuality` و`refreshAssessments` | تجلب آخر البيانات من الخادم بعد كل تعديل أو عند فتح الصفحة. |
| `views` | مجموعة دوال ترسم صفحات الواجهة العربية مثل المستخدمين والمعايير والتقويمات. |
| `handle` | يستقبل ضغطات الأزرار ويربط كل زر بطلب API مناسب. |
| `modal` | ينشئ نافذة إدخال موحدة ويحفظ البيانات عبر الدالة التي تمرر إليه. |

## 7. كيف تشرح المشروع للدكتور

يمكنك القول: «الواجهة مكتوبة بـ JavaScript عربي RTL، لكن مصدر الحقيقة هو Laravel وMySQL. عند الضغط على حفظ، تستدعي الواجهة رابط API محميًا بالصلاحية. يعيد الـ Controller التحقق من الدور والنطاق، ثم يحفظ داخل معاملة قاعدة البيانات ويسجل العملية في `audit_logs` أو ينشئ إشعارًا عند الحاجة. لذلك يظهر التغيير من الهاتف والكمبيوتر بعد تحديث البيانات.»

## 8. أوامر التحقق قبل المناقشة

من Terminal داخل مجلد المشروع نفذ:

```powershell
php artisan test
vendor\bin\pint --test
node --check public/platform/js/app.js
```

هذه الأوامر لا تغير البيانات؛ هي تتحقق من الاختبارات وتنسيق PHP وصحة صياغة JavaScript.
