# منصة اليمن لتقييم وضمان جودة واعتماد مؤسسات التعليم العالي

مشروع تخرج أكاديمي مبني بـ Laravel وMySQL، بواجهة عربية RTL. يدير دورة الجودة من التقويم الذاتي والأدلة إلى التقييم الخارجي، التحسين، وقرار الاعتماد.

> المشروع نموذج أكاديمي؛ قرار الاعتماد لا يصدر آليًا بل تسجله الإدارة المركزية المخولة داخل النظام.

## المتطلبات

- PHP 8.2 أو أحدث مع امتدادات MySQL.
- Composer وMySQL 8 أو MariaDB.
- Node.js اختياري عند تعديل أصول Vite؛ الواجهة الحالية تعمل من الملفات المنشورة داخل `public/platform`.

## التشغيل المحلي

1. أنشئ قاعدة بيانات MySQL باسم `yemen_qa`.
2. انسخ `.env.example` إلى `.env` وعدّل `DB_DATABASE` و`DB_USERNAME` و`DB_PASSWORD`.
3. نفّذ الأوامر التالية داخل مجلد المشروع:

```powershell
composer install
php artisan key:generate
php artisan migrate --seed
php artisan serve
```

4. افتح العنوان الذي يظهر في الطرفية، وغالبًا `http://127.0.0.1:8000`.

## حسابات العرض

بعد تشغيل الـ Seeder استخدم حسابات العرض الموجودة في شاشة الدخول. كلمة المرور الأولية:

```text
Demo@1234
```

## الأدوار

- مدير النظام: الحسابات والصلاحيات والبنية المؤسسية وسجل التدقيق.
- الإدارة المركزية: المعايير والدورات والفرق والتقارير والاعتماد.
- مسؤول الجامعة: التقرير الجامعي والتحسين وطلب الاعتماد.
- مسؤول الكلية: التقويم الذاتي والأدلة وإجراءات التحسين.
- العميد: مراجعة الأدلة وتقارير الكلية.
- المقيم الخارجي: الزيارات والتقييم والتقرير الخارجي للتكليفات المسندة إليه.

## المسار الوظيفي

1. إعداد المعايير ودورة التقييم.
2. التقويم الذاتي للكليات والأدلة.
3. اعتماد تقارير الكليات والتقرير الجامعي.
4. فريق التقييم وتعارض المصالح والزيارة الميدانية.
5. التقييم والتقرير الخارجيان.
6. تحليل الفجوات وخطة التحسين.
7. طلب الاعتماد والقرار النهائي.
8. التقارير والإشعارات وسجل التدقيق.

## التحقق قبل التسليم

```powershell
php artisan migrate --force
vendor\bin\pint --test
php artisan test --testsuite=Feature
node --check public\platform\js\app.js
php artisan view:cache
```

## حدود النسخة الحالية

- تصدير CSV وWord وPDF متاح من الواجهة كناتج عرض، ويحتاج تطويرًا لاحقًا لإخراج قوالب رسمية ثابتة.
- النسخ الاحتياطي الآلي والإشعارات بالبريد والتكاملات الحكومية خارج نطاق النسخة الأساسية.
- قبل أي نشر فعلي: غيّر كلمات مرور العرض واضبط `APP_ENV=production` و`APP_DEBUG=false`.
